Informations

Une fois créé, l'agent sera déployé via Docker et se connectera automatiquement au serveur via WebSocket.

  • L'agent recevra un ID unique généré automatiquement
  • La connexion WebSocket sera établie sur le port 8765
  • Vous pourrez ensuite exécuter des commandes depuis la liste des agents
